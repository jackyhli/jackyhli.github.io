# jackyhli.com

My personal portfolio, built to look like a camera monitor: a REC timecode, film grain, clapperboard slates on each page, and a filmstrip menu that ties it all together.

**Live at [jackyhli.com](https://jackyhli.com)**

## Pages

- **About:** bio, education, and a contact sheet of stills
- **Work:** experience, research, and awards, laid out like a film's credits
- **Projects:** selected projects, each with an illustration and photos you can switch between like camera angles
- **Videos:** trailers, reels, and promos I've shot and edited
- **Contact:** a message form and direct links

## How it's built

- Plain HTML, CSS, and JavaScript, with no framework and no build step
- Hosted on GitHub Pages with a custom domain
- Fonts are stored in the repo (Instrument Serif, Inter Tight, IBM Plex Mono, all under the SIL Open Font License), so the site doesn't rely on a font service
- Responsive from large monitors down to small phones, with page transitions and reduced motion for visitors who turn animations off
- The contact form sends through Formspree, and the email address is only put together when someone clicks it, which keeps scrapers from collecting it
